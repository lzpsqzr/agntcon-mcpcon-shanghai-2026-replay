全天十四条演讲，收敛成四个词

完整的分析写在公众号稿里，这里只留最核心的四组判断。

01身份：agent 你是谁？

阿里云给每个 agent 发"电子身份"绑 RAM 权限；蚂蚁用 JWT 按 RFC 8693 逐跳嵌套委托链。

最喜欢的设计：scope 故意不放进 JWT——凭证只证明"你是谁"，权限动态查，才可撤销、可审计。想想那些躺在配置里三年没换的 API key。

02隔离：所有人都在做沙箱

腾讯 Cube Sandbox 快照路径 50ms；头部模型厂 RL 后训练每分钟 10–16 万次沙箱并发。

刘超更硬核：hypervisor 切两域，实时控制留给 Zephyr，agent 关在 Linux 域。一个防交互失控，一个防生产线被搞停——硬度不同，逻辑同源。

03安全：MCP 是管道，不是金库

2.4 万个泄露密钥；WhatsApp 和 GitHub 官方 MCP 两案：没人破解加密，破解的是权限。

可信服务器 ≠ 可信结果。致命三要素 = 私有数据 + 不可信内容 + 对外通信；Anika 的四道防线（准入→上下文→动作→出站）就是在逐条拆三角。

04记忆：向量检索会"自信地答错"

同一份数字孪生，向量 RAG 答错，图 RAG 答对还画出推理链。

决策树：事实查询 → 参数化 MCP 直查；多跳推理 → 建图（配 CDC 保新鲜）；模糊找文档 → 才轮到向量 RAG。一套 RAG 打天下是偷懒。

几个行业信号

智能路由的冷水

多模型融合、多 agent 讨论，benchmark 无可见提升；路由只优化成本与延迟，"上限由模型决定，下限由推理成本决定"，开销必须 <10%。

渗透率的想象

约 1% 的企业软件包含 agent，2028 年预测升至 33%。是预测不是事实，但 agent 进生产已是全场反复出现的议题。

中国厂商的浓度

腾讯、阿里、蚂蚁、字节、华为、阶跃、Intel 都带去了具体工程实践；Cube Sandbox、Ling、DeerFlow 提供了会后继续验证的入口。
